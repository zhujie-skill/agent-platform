# ADR-004：宿主机优先的本地开发方式

- 状态：Accepted
- 日期：2026-10-01

## 背景

项目当前重视快速启动、错误可见和断点调试，不需要应用云部署。强制容器化会增加 Windows 路径、文件监听和网络排错成本。

## 决策

日常开发默认在宿主机直接运行 Next.js 与 FastAPI，使用统一 PowerShell 脚本启动。Docker Compose 延后到需要可复现演示和隔离 Worker 时加入。

## 结果

首次准备需要安装 Node.js、pnpm 和 Python。开发日志与热更新更直接，云 PostgreSQL 不需要本地数据库容器。

## 重新评估条件

当跨平台环境差异显著、团队规模扩大，或不可信工具必须隔离执行时，引入 Compose 作为主要运行方式。
